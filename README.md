# Liver Plugins

Plugins for [Revenge](https://github.com/revenge-mod), maintained by Livie.

## Install

Add this repository's index in **Settings** > **Revenge** > **Plugins** > **[+]**:

```
https://lvwmwm.github.io/liver-plugins/index.json
```

## Plugins

| Plugin | Description | Authors | Version |
| --- | --- | --- | --- |
| [Permission Viewer](plugins/permission-viewer) | Inspect the permissions a server, channel, role, or member has. | Livie | 1.0.0 |
